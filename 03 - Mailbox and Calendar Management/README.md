# Task 1 - Configure Mail Forwarding

## Objective

Configure email forwarding for a user mailbox to automatically redirect incoming emails to another mailbox while retaining a copy in the original mailbox.

---

## Implementation

I accessed the user's mailbox settings and enabled automatic email forwarding. I specified the forwarding address, enabled the option to keep a copy of forwarded emails in the original mailbox, and saved the configuration.

---

## Navigation

**Microsoft 365 Admin Center** → **Users** → **Active users** → **Mario Katoch** → **Mail** → **Manage email forwarding**

---

## Outcome

I successfully configured email forwarding for the user mailbox, ensuring incoming emails are automatically redirected while retaining a copy in the original mailbox. This is a common IT Support task used during staff absence, role changes, or mailbox management to maintain uninterrupted communication.
