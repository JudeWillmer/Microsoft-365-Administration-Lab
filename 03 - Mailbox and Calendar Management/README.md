# Task 1 - Configure Mail Forwarding

## Objective

Configure **email forwarding** for a user mailbox to automatically redirect incoming emails to another mailbox while retaining a copy in the original mailbox.

---

## Implementation

I configured **email forwarding** for the user's mailbox through the **Microsoft 365 Admin Center** by enabling automatic forwarding and specifying a forwarding email address. I also enabled the option to **keep a copy of forwarded emails** in the original mailbox before saving the configuration.

---

I successfully configured **email forwarding** for the user mailbox, ensuring incoming emails are automatically redirected while retaining a copy in the original mailbox.
