# Task 1 - Outlook Overview and Navigation

## Objective

Become familiar with the Microsoft Outlook interface and explore the features most commonly used when supporting end users in a Microsoft 365 environment.

---

## Implementation

I explored the Microsoft Outlook interface to become familiar with the features and navigation commonly used during IT Support and Help Desk tasks.

I reviewed the main Outlook interface, including **Mail**, **Calendar**, **People**, and **Tasks**, before exploring the **Home**, **Send/Receive**, and **View** ribbons.

Particular attention was given to the **View** settings, as these are frequently used to resolve common user issues such as missing Reading Panes, hidden Folder Panes, incorrect email sorting, and customised inbox layouts. I also explored **Rules and Alerts**, **Junk Email Options**, the **Address Book**, message **Categories**, and Outlook's **Calendar** to understand where these features are managed.

---

## Navigation

```text
View
↳ Layout
↳ Change View
↳ Arrange By

Home
↳ Rules
↳ Junk

Address Book

Calendar

```

## Outcome

Successfully explored the Microsoft Outlook interface and became familiar with the navigation, settings, and features commonly used to support end users. This included understanding where to manage Outlook layout settings, email rules, junk email options, contacts, categories, and calendar features.
