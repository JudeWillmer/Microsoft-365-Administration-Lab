# Task 1 - Outlook Overview and Navigation

## Objective

Become familiar with the Microsoft Outlook interface and explore the features most commonly used when supporting end users in a Microsoft 365 environment.

---

## Implementation

I explored the Microsoft Outlook interface to become familiar with the features and navigation commonly used during IT Support and Help Desk tasks.

I reviewed the main Outlook interface, including the **Home**, **Send/Receive**, and **View** ribbons, while becoming familiar with Outlook's Mail, Calendar, and contact management features. I also explored commonly used options such as **Rules**, **Junk Email**, and other mailbox management features, noting that some commands are accessed through the **More (...)** menu in the latest version of Outlook.

Particular attention was given to the **View** settings, as these are frequently used to resolve common user issues such as missing Reading Panes, hidden Folder Panes, incorrect email sorting, and customised inbox layouts. I also explored the **Address Book**, message organisation features, and Outlook's **Calendar** to understand where these functions are managed.

---

## Navigation

```text
Home
↳ More (...)
   ↳ Rules
   ↳ Block

View
↳ Layout
↳ Change View
↳ Arrange By

Address Book

Calendar
```

---

## Outcome

Successfully explored the Microsoft Outlook interface and became familiar with the navigation, settings, and features commonly used to support end users. This included understanding where to manage Outlook layout settings, mailbox rules, blocked senders, contacts, and calendar features within the current Microsoft 365 Outlook interface.
