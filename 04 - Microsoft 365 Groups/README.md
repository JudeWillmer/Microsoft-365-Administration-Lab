# Task 1 - Create a Microsoft 365 Group

## Objective

Create a new **Microsoft 365 Group** to provide a collaborative workspace for users, including a shared mailbox, shared calendar, Microsoft Teams, and a SharePoint site.

---

## Implementation

I created a new **Microsoft 365 Group** through the **Microsoft 365 Admin Center** by providing the group name, description, owners, members, and configuration settings. During setup, I configured the group as **Public** and enabled **Microsoft Teams** integration to provide a shared collaboration environment.

After completing the wizard, I verified that the **Operations** group was successfully created and appeared within **Active teams & groups**, confirming it was ready for use across Microsoft 365 services.

---

## Navigation

```text
Microsoft 365 Admin Center
└─ Teams & groups
   └─ Active teams & groups
      └─ Add a Microsoft 365 group
```

---

## Outcome

I successfully created a new **Microsoft 365 Group** and confirmed it appeared within **Active teams & groups**. This demonstrates a common Microsoft 365 administration task used to provision collaboration spaces that include shared email, calendars, Microsoft Teams, and SharePoint resources.

# Task 2 - Manage Group Membership

## Objective

Manage **Microsoft 365 Group membership** by adding a user to an existing group and verifying that access to the group's collaborative resources was successfully assigned.

---

## Implementation

I managed the membership of the **HR Microsoft 365 Group** through the **Microsoft 365 Admin Center** by selecting the group, opening the **Membership** settings, and adding **Nancy Smith** as a member.

After completing the change, I verified that the user appeared within the membership list. I also reviewed the process of removing members when access is no longer required.

---

## Navigation

```text
Microsoft 365 Admin Center
└─ Teams & groups
   └─ Active teams & groups
      └─ HR
         └─ Membership
            └─ Members
               └─ Add members
```

---

## Outcome

I successfully added **Nancy Smith** to the **HR Microsoft 365 Group** and confirmed that the updated membership was displayed. This demonstrates a common **IT Support** task used to manage access to shared conversations, files, calendars, and other Microsoft 365 collaboration resources.
